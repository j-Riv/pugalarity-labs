# Pugalarity Labs
Satirical fictional AI company site (pugalaritylabs.com).

## Tone
Deadpan corporate AI hype. Never break character, never explain the joke.

## Rules
- Original art only: the project's own SVG/CSS and the owner's own generated images (in `src/assets/`). No stock photos or third-party art. No real company names, logos, trademarks, or people.
- Static site, no backend, no real personal data collection, no secrets. The one allowed exception is the cookieless Cloudflare Web Analytics beacon in `Base.astro`.
- Keep dependencies minimal.

## Verifying changes
Run the build and fix any errors before reporting a task as done.
